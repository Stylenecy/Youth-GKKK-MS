## 6. Hal yang diragukan

1. **3 nickname duplikat** (Dian, Nathan, Joshua) — import SQL pakai `WHERE nickname = '...'` untuk lookup. Saat ada 2 Nathan, query return 2 baris dan INSERT gagal. Perlu disambiguasi manual dengan tambah kondisi (misal: `WHERE nickname = 'Nathan' AND birth_date = '2005-12-25'`).

2. **"orang padang" dan "orang manado"** di Cross 2 — bukan nama orang. Mungkin kategori untuk anggota yang dari luar kota? Perlu dikonfirmasi Dex.

3. **Mapping skill** — kategori di Excel (WL/SINGER/PEMUSIK/SOUND/MULTIMEDIA/USHER) saya mapping ke enum skills. Mungkin ada kategori yang tidak cocok — perlu review setelah data masuk.

4. **Pseudo-UPSERT by nickname** di cross.sql dan events.sql — jika nickname tidak ditemukan di profiles, INSERT menjadi NULL (tidak error, tapi data hilang). Perlu verifikasi setelah profiles terisi.

5. **Format tanggal di Excel tidak seragam** — ada yang `datetime object`, ada yang string "5 April 2004", ada yang "15 Maret 2004". Parser sudah handle 3 format, tapi mungkin ada edge case yang terlewat. Perlu spot-check setelah import.
